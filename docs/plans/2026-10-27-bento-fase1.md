## Decisões

Execução nativa no ramo `codex/bento-fase1`, sem replicar ambiente nem dados pessoais em worktree. O escopo reversível está autorizado pelo pedido e AGENTS; não há nova rodada de aprovação. O documento fixa a direção visual, dispensando alternativas de layout nesta fundação.

Os componentes ficam preparados, mas não são usados para montar telas de fases futuras. O CSS legado preserva geometria, agrupamentos e navegação; os tokens antigos passam a referenciar a base Bento. Dados demonstrativos têm identificação explícita nos arquivos e nos relatórios de evidência, nunca são inseridos no app real.

## Foco da revisão

1. Injeção em slug, estado, texto, size e target: nenhum atributo ou estilo arbitrário deve passar.
2. Dados desconhecidos/zero/excedentes e números não finitos: distinguir ausência, resultado real e porcentagem limitada visualmente.
3. Gerador apontado para banco real, pasta existente, caminho indireto ou symlink: recusar antes de abrir qualquer Repository.
4. CSS global não pode selecionar fonte de ícones ou quebrar foco, tabelas, formulários, radios e acesso móvel.
5. Capturas devem usar o mesmo cenário antes/depois, porta separada, fonte local confirmada e nenhum pedido remoto próprio.
